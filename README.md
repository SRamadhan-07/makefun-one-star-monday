A tiny Python program that writes a single line to `/output/entry.txt`:
a one-star review of Monday written as if Monday were a restaurant —
booked for 7 a.m., seated at dread, served meetings and cold soup,
and somehow open every week.

## How to run

```sh
python3 main.py
```

This creates `/output` if needed and writes the entry line to
`/output/entry.txt` (UTF-8, exactly one line, no trailing newline).
No dependencies beyond the Python 3 standard library.
